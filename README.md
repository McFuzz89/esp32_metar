# E-Ink Flight Deck

**DISCLAIMER**: This is a purely hobbyist project; the source code was entirely vibe-coded in Gemini as the author is neither a software engineer nor even a script-kiddie. 

**TL;DR ->** ESP-32 based E-Ink display with 10 airport memory capacity (configurable via a web interface) allowing scrolling through METAR, TAF and Winds Aloft information per airport using a rocker switch. Data is fetched at the middle and top of every hour via WiFi. 

**NOTE:** Make sure to connect to a 2.4GHz WiFi network! Roughly 37 day battery life using a 2000 mAh battery at 2 refreshes per hour! 

**Hardware Used:**
 * Elecrow CrowPanel 5.79" E-Ink display with built in ESP-32 SoC. Other 5.79" displays may work, but you may need to modify the code to match hardware pinouts for the buttons, etc.
 * 3.7v 2000 mAh LiPo battery with a JST-PH 1.0mm plug -> https://www.ebay.com/itm/175054540603?var=474220902789 MAKE SURE YOUR BATTERY HAS THE CORRECT POLARITY!!!

**Quick button reference:** 
 * Top button short press -> return to home airport (slot 1 in the airport config)
 * Top button 3 second press -> enter configuration mode which enables a web interface to configure airports, runways, TAF fallback and reset the battery counter after a charge. Webserver is on a timer and will shutoff/revert to normal function if no input is detected.
 * Top button 6 second press -> enter WiFi cnofiguration mode (to change to a different network). 
 * Rocker switch - up/down motions to swap between saved airports, press to select.
 * Bottom button short press -> swap between METAR, TAF, Windos Aloft
 * Bottom button 3 second press -> swap between dar/light themes
 * Bottom button 6 second press -> reset battery count.

**How to deploy:**
 * Install the Arduino IDE
 * Install the libraries
 * Configure the IDE per the below screenshots.
 * Connect display via USB-C
 * Paste the code. You can edit the code before deployment to add your own airports - or can do it after using the UI.
 * Deploy!

   After deployment, the display may go straight into wifi selection mode; follow the instructions on the screen - you can use a phone to connect to the WiFi network shown on the display which will open a captive portal page allowing you to select and connect to your network. Once that is done, enter the configuration menu (top button 3 second press), then on your computer or phone open a web browser and enter the IP address shown on the display to enter the configuration menu (see screenshot at the bottom of the Readme).

**Longer list of features (generated by Gemini, reviewed by a human):**

Aviation Data & Intelligence

 * Tri-Mode Weather Engine: Cycle between live METAR (Current), TAF (Forecast), and Winds Aloft using physical hardware buttons.
 * Smart Runway Database: A custom-built parsing engine that allows you to store specific runways for each airport.
 * Dynamic Runway Snapping: The code automatically calculates crosswind components against your saved runway list and "snaps" the display to the best available piece of asphalt for the current wind.
 * TFR Detection (experimental): Active NOTAM monitoring that triggers a prominent "TFR" warning box on the METAR screen if restrictions are detected.
 * TAF Fallback: Programmable logic that automatically fetches TAF data from the nearest programmed major hub if your selected airport doesn't provide its own forecast (configurable in airport config menu).

Visuals & Custom Avionics UI

 * High-Contrast Flight Alerts: The Flight Category box (VFR/MVFR/IFR/LIFR) automatically inverts from an outline to a solid black block with white text during poor weather for instant "across-the-room" recognition.
 * Custom Vector Weather Icons: Pixel-perfect, high-readability icons to indicate sunny, cloudy, rainy or thunderstorm conditions.
 * Variable Windsock: A custom-drawn windsock icon that physically droops or stiffens depending on wind speed.
 * True Compass Rose: Features a dynamic wind vector arrow and "VRBL" or "CALM" logic for unstable conditions.
 * Theme Inversion: A "Dark Mode" vs. "Light Mode" toggle (3-second bottom button hold) that flips the entire screen's color palette.

Power & Battery Management

  * ~38 Day Battery Life With Optimized Sleep Routing: CrownPanel can charge a LiPo battery not show its voltage. To provide battery life estimation, a 2000 mAh 3.7v battery was charged to 4.2v and took about 2000 refresh cycles to deplete in roughly 40 days. Using 1800 cycles for a 3-notch batter meter (600 cycles per notch) provides for about 38 days with some reserve. NOTE: Elecrow CrowPanel displays can be finnicky when it comes to charging - you may need to plug a charger first and then plug the battery in order for it to start charging. 
  * Staggered Cold Boot: A power-sequencing routine that boots the e-ink screen before the Wi-Fi radio to prevent current spikes from tripping the battery's protection circuit.
  * Catch-Window Logic: The CPU only wakes up at the top and bottom of the hour (e.g., :00 and :30) to pull fresh data, immediately returning to deep sleep once the pixels are set. A button press will wake up the CPU outside of the update windows for user-triggered actions.

Configuration & Connectivity

  * Web-Based Captive Portal: A mobile-friendly setup screen (6-second top button hold) that lets you join new Wi-Fi networks without ever touching the code.
  * Airport Configuration Tool: A custom internal web server (3-second top button hold) to update your 10-airport memory and runway database via any phone or laptop browser.
  * Interactive Selector: Real-time visual feedback using the physical rocker switch to scroll through your saved airports.
  * Defensive API Handling: Robust logic that handles 204 No Content API outages and DNS failures gracefully with custom error screens instead of crashing.
